HOW IT WORKS

From Order to Settlement

xCrossSwap connects swap users with Relayers. Instead of relying on a single liquidity pool, orders can be executed by independent network participants.

01

Create Order

The user selects the source chain, target chain, assets and amount, then creates a cross-chain swap order.

02

Relayer Takes Order

A Relayer monitors available orders and selects an order that matches its supported route and execution conditions.

03

Pre-Fund

The Relayer provides the target-chain asset to the receiving address using its own available working capital.

04

Settlement

Once the swap conditions are fulfilled, the source-chain asset is settled to the Relayer together with the applicable network reward.
